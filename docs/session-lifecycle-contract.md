Every target command is `{version:1,inputId,sessionId,at,expectedRevision,authority,payload}`. Authority is authenticated ingress evidence for inbox admission; all owner writes carry `{owner,fence}`. Alarm evaluation additionally carries `{evaluatorOwner,evaluatorFence,expectedAlarmRevision}`. Times and authentication evidence are captured before DEC, and after any asynchronous authorization they are revalidated against the current snapshot. A decision returns either `{kind:"refused",code,receiptAction?}` or `{kind:"apply",expectedRevision,authority,actions,consumeInboxIds,regionPatch,effects}`. An effect descriptor is `{kind,causingActionId,idempotencyKey,payload}`. APPLY returns `{ok:true,revision,receipts,effects}` or the current `CommitResult` refusal shape. Revision/fence refusal never dispatches the decision's effects.

Events in the tables below name **commands**, not invented current exports. Current action kinds and fields are spelled out in section 6. New command payloads include all fields shown in their region product; `request.open` and `occurrence.open` carry the complete product with initial state. Result commands carry the identity, expected current state, terminal, reason/output, and captured time. Unknown versions, extra schema fields, absent identity, illegal source/event pairs, and inconsistent products are read-only `invalid_transition` from DEC. Only explicitly listed transitions are admitted. Within a table, the common precedence rules below run before event-specific guards; a catch-all applies only after every earlier case fails. Cross-region rows compose one decision/transaction, not competing transitions.

### Operation and wave region

Post-body exception recovery is a **target** extension, not a claim that HEAD catches these exceptions. `executeBatch` awaits the wave before processing results in call order (formerly `packages/agent/src/executor.ts:198-275` (pre-#1247; now `packages/agent/src/core/loop/executor.ts`); the wave scheduler lives in `packages/agent/src/core/loop/executor.ts` since #1247, `core/` since #1276); post policy, reverter, result projection or commit can then throw (formerly `packages/agent/src/executor.ts:354-381` (pre-#1247; now `packages/agent/src/core/loop/executor.ts`)). RECOVERY captures `{operationId,site:post_policy/reverter/result_commit,error:{name},classification:local_transactional/endpoint_idempotent/read_back_reconcilable/ambiguous_no_replay,proof:absent/applied/reverted/indeterminate,proofReceipt:null/{id,digest},revertReceipt:null/id,rawSettled}`. `reverted` requires a durable receipt of the **registered** reverter's successful return; a thrown reverter is never proof of rollback. Local transaction read-back, an endpoint's same-key receipt, or authoritative correlated read-back respectively may prove absent/applied; absent such evidence, proof is indeterminate. A decisive proof carries its source proofReceipt; indeterminate proof has proofReceipt null. Ambiguous-no-replay always has indeterminate proof; incompatible classification/proof/receipt combinations are invalid_transition before recovery precedence. No post-body exception path re-executes the body or fabricates a post-policy verdict.

Recovery precedence is: read the original terminal slot first; if present, preserve it even when commit threw after persistence. Otherwise, if read-back is unavailable or the session cannot commit (lost/expired lease, stale revision, sealed-turn execution port, or unavailable storage), choose recovery_pending. Only a fresh valid owner with an empty slot may commit the classified result. A failed recovery commit repeats the same read-back/authority decision, never a blind append. For **every** recovery row, patch only this operation in retainedEffects: remove it iff rawSettled, otherwise retain/add it until its exact settlement signal; preserve other operations and retainedRunner. Store the captured error in retainedFailure; no recovery row releases a foreign lease. A pending overlay is not durable evidence: after process loss the still-unsettled intent is reclassified from persisted evidence. Proof/error/reverter evidence that can be committed is retained in the result's `recovery` field.

## 4. Original request, late input, and delivery

HEAD decision symbols are `attachReply` in protocol/wait/fold.ts, `approvals.answer` in agent/executor-approval.ts, `Approval.decide`/`decision` in protocol/approval/fold.ts, and delegation's nested `settle`/`settleFromReply`. Their different current persistence paths are in the receipts. In particular, HEAD Wait rejection calls `WaitStore.commit` but does not persist a Wait fact; it publishes ReplyRejected. `executeWaitRoute` lazily expires `deadline_passed` and writes `recordRouteNotDelivered`. HEAD `approvals.answer` rejects an expired answer even when its timer callback has not run. HEAD delegation `settleFromReply` has no deadline check of its own. REQUEST replaces these independent logical judgments at #969; these are not claims that the new receipts already ship.

**Target `request.answer_admission` is unconditional.** Capture authenticated receipt time from the owner clock, not the sender. After validating the session lease (no stale writer may even append a refusal), apply this order: equivalent processed `inputId` -> return its original receipt; divergent reuse -> read-only invalid_transition; `receivedAt >= deadline` -> `reply.late_unknown`, and if still open, expire the request in the same batch; before deadline, binding/principal/domain/input hash mismatch -> `reply.rejected`; terminal before deadline -> `reply.duplicate`; otherwise attach/resolve through the single open-state CAS. A late answer never reopens the old request and never becomes new inbox input, even if the timer is delayed. This explicitly supersedes logical post-terminal follow-up admission for this target. Physical reply correlation is still retained.

## 5. Alarm and occurrence transition product

Target authority is ALD/ALA/ALX through DEC/APPLY/DISPATCH. HEAD `sessionStopEvidence` only reads current actions/approvals/armed ids. `Alarm.Status` already lists four states, but there is no HEAD occurrence evaluator to cite or delete. The census assigns its existing evidence reader and alarm primitives to #971.

Canonical identities: `J` is sorted-key JSON encoding used by existing `canonicalDigest`; all keys below are **UTF-8 `canonicalKey` bytes**, not ad hoc string concatenation. Active key is `K([sessionId,kind,controlKey])`, where `controlKey` is the authenticated caller's stable monitor identity, stored in spec; a scheduled one-shot defaults to `K([fireAt,spec.value ?? null])`. Armed, paused, and fired-with-open-occurrence reserve this key. A cancelled or completed one-shot releases it. Rearm uses the same alarm id, increments epoch, and replaces its reservation atomically; another alarm reserving the key refuses `active_key_conflict`.

Transport duplicate identity is `(alarmId,epoch,sourceKey)`, with `sourceKey` captured from a timer fire slot or backend event/cursor. Repeating it returns the recorded occurrence receipt; differing payload under it refuses. Consecutive polling suppression is a separate tuple `(alarmId,epoch,lastBatchHash)`; equality produces a **new terminal deduped occurrence** only for a newly observed sourceKey. It does not overwrite the previous occurrence's terminal. Takeover preserves epoch, cursor and lastBatchHash. Explicit rearm increments epoch and clears lastBatchHash/cursor only according to the admitted source restart mode, so an explicitly restarted poll A may notify again. Wake key is `(destinationSessionId,occurrenceId)`; duplicate wake returns the original RCV receipt.

Every alarm control command includes `{alarmId,expectedAlarmRevision,epoch,at,owner,fence}`; every evaluator command includes those identity/revision fields plus `{evaluatorOwner,evaluatorFence,sourceKey,batchHash,cursorBefore,cursorAfter}`. Session lease is acquired before ALA mutates session actions, even while the session's runner sleeps. Evaluator lease alone cannot write session history. All control mutations fence evaluator callbacks by incrementing evaluator fence and clearing owner/expiry before physical cleanup.

**Alarm refusal precedence (first match wins):** (1) malformed/missing/mismatched alarm/occurrence identity -> invalid_transition; (2) invalid session authority or old/expired evaluator identity/fence -> stale, before terminal comparison or dedupe (acquire/takeover checks expectedEvaluatorFence instead of requiring a live evaluator); (3) previously processed inputId -> original receipt on equal payload, invalid_transition on divergent reuse; (4) old epoch -> stale; repeated transport sourceKey for fire/new-poll only -> original receipt on equal payload, invalid_transition on divergent reuse; (5) a result for a terminal occurrence -> original receipt on equal result digest, terminal_conflict otherwise; (6) differing expected session/alarm revision -> revision refusal; (7) event-specific guards below, then the catch-all. A control replay of the identical rearm input therefore returns its receipt even though that control advanced epoch; a fresh input with old epoch is stale. Thus an old e/f1 completion of cancelled O1 in A_PAUSED is stale, never terminal_conflict. A fresh current evaluator's differing result for a terminal occurrence is terminal_conflict. Before terminality, at >= occurrence deadline selects expiry even for a failed/completed result; only earlier results can fail, complete or consume notification budget. A fire for a new sourceKey with equal lastBatchHash takes the deduped branch, not the ordinary fire branch.

### 6.6 Totality/property harness

HARNESS generates the Cartesian product of the finite region states and event tags above, and two-way permutations of contenders built against the same revision (reply/cancel/timeout; interrupt/answer; fire/pause/cancel; renew/takeover; duplicate input/result). Pure DEC is evaluated before APPLY; the loser is retried only as a **new decision against the winning snapshot**, never by dispatching its old proposal. Rejecting a late reply may append its explicit receipt; rejecting a stale lease cannot. For each accepted action prefix assert the named snapshot, exact next ordinal, terminal count per original result slot <=1, input-consumption count <=1, whole-wave gate body count 0, sequential-start barrier, and effect descriptor identity. Corrupt owner, fence, revision, parent session, input hash, generation, domain revision, cursor, deadline edge, and duplicate id independently; each must take the specified refusal branch. Replaying each exact prefix from its named seed must equal that prefix snapshot with dispatched effects `[]`. Refusal receipts are part of replay input, not silently discarded.

Include every post-body recovery classification crossed with absent/applied/reverted/indeterminate proof, terminal found/empty/read-back unavailable, current/lost write authority, and raw settled/unsettled. Inconsistent proof products refuse; accepted products must select exactly one section 3 destination, keep a pre-existing terminal, and patch only the affected retained operation. Exercise both alarm terminal-result digests under current and old evaluator fences, exact rearm replay after epoch advancement versus fresh stale-epoch input, and deadline-versus-failure-versus-budget precedence. An ineligible takeover of an evaluating live source must append pause + cancellation atomically, clear evaluator owner/expiry, increment its fence, leave no nonterminal occurrence, and permit an explicitly supported owner resume without borrowing the eligible-takeover row. Inject failure between child terminal/outbound inserts and after destination commit/before source ack; assert the section 6.4 pair snapshots. These finite cases are construction requirements, not a claim that the target implementation already ships.

Before triggering asynchronous input, register the exact action-commit/runner-entry/body-settlement/abort/source-close signal; await that promise with a 2-second failure deadline. Time itself is advanced by the fixture clock and the captured timer callback, never by sleeping. ### Receipt semantics

`move` removes the old writer at the same cutover as its exact target; `delete` has no consumer; `keep` preserves the current symbol at its source path. A parent row never includes a separately listed child. Every test symbol above is assigned to one sole child; in particular, positional history belongs to #972 and SQLite recovery belongs to #970, not both. `migrate` preserves identity and immutable evidence through a guarded forward migration; `refuse` retains bytes and rejects removal; `drop` is unused because no export/backup decision exists. The exact target test registrations named in section 6.7 are not silently counted as current symbols.

### Mechanical receipt and citation checks

Run this from the worktree. It verifies exclusivity **and** cited declarations, not merely that a line number is smaller than a file's length. It reads the receipt table and current source, including a completeness check for the fully inventoried approval exports and three suites. Future target-test keys are checked for exclusivity separately, never passed off as HEAD declarations.

```python
import pathlib, re, subprocess
root = pathlib.Path.cwd()
text = (root / "docs/session-lifecycle-contract.md").read_text()
owner, seen, count, targets = None, {}, 0, 0
for line in text.splitlines():
    heading = re.match(r"### #(969|970|971|972|973) production", line)
    if heading:
        owner = heading[1]
    future = re.match(r"\| target-test \| `([^`]+)` \| future registration; no HEAD span", line)
    if future:
        assert future[1] not in seen, ("duplicate target", future[1])
        seen[future[1]] = owner
        targets += 1
    row = re.match(r"\| (prod|test) \| `([^`#]+)#([^`]+)` \| `([^`]+):(\d+)-(\d+)`", line)
    if not row:
        continue
    kind, file, symbol, cited, first, last = row.groups()
    symbol = symbol.replace("\\|", "|")
    key = file + "#" + symbol
    assert key not in seen, ("duplicate", key, seen.get(key), owner)
    seen[key] = owner
    assert file == cited, (file, cited, symbol)
    source = (root / file).read_text().splitlines()
    assert 1 <= int(first) <= int(last) <= len(source), (file, first, last)
    leaf = symbol.rsplit(".", 1)[-1]
    needle = symbol.rsplit(" :: ", 1)[-1] if kind == "test" else leaf
    hits = subprocess.run(["rg", "-n", "-F", "--", needle, file],
                          check=True, capture_output=True, text=True).stdout
    assert any(int(first) <= int(hit.split(":", 1)[0]) <= int(last)
               for hit in hits.splitlines()), ("missing symbol", key, first, last)
    if kind == "prod":
        span = "\n".join(source[int(first)-1:int(last)])
        declared = (r"\b(?:function|class|interface|type|namespace|enum|const|let)\s+"
                    + re.escape(leaf) + r"\b|\b" + re.escape(leaf) + r"\s*\??\s*\(")
        # VariableDeclaration ranges begin after 'const'; its source line retains it.
        assert re.search(declared, span), ("not a declaration", key, first, last)
    count += 1
for file, first, last in re.findall(r"((?:packages|apps)/[\w/.-]+):(\d+)-(\d+)", text):
    lines = (root / file).read_text().splitlines()
    assert 1 <= int(first) <= int(last) <= len(lines), (file, first, last)
# Completeness for the replaced approval entries and the three fully inventoried suites.
for file, prefix in [("packages/ledger/src/approval/index.ts", "ApprovalStore."),
                     ("packages/protocol/src/approval/fold.ts", "")]:
    for name in re.findall(r"export function (\w+)\(", (root / file).read_text()):
        assert file + "#" + prefix + name in seen, ("omitted authority", file, name)
for file in ["apps/openomni/test/delegation.test.ts",
             "packages/ledger/test/approval/store.test.ts",
             "packages/protocol/test/approval-fold.test.ts"]:
    registrations = re.findall(r'^\s*test\("([^"\n]+)"', (root / file).read_text(), re.M)
    for name in registrations:
        keys = [key for key in seen if key.startswith(file + "#")
                and key.rsplit(" :: ", 1)[-1] == name]
        assert len(keys) == 1, ("omitted/duplicate registration", file, name, keys)
assert count > 0 and targets > 0
print(f"{count} HEAD source/test symbols; {targets} separate target-test receipt; duplicate owners: 0")
```

The checker treats a qualified source symbol as one key even if multiple children use it. A deliberate duplicate row under another child must fail; an unknown symbol with an in-range line must fail. Neither formatting/lint nor this lexical checker alone proves transition semantics; section 6's behavioral vectors are the separately owned conformance oracle.
